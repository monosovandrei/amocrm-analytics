# Локальное распознавание звонков

Обработка использует только архив на сервере. transcribe.py не скачивает модели, не обращается к API и не отправляет записи наружу. Запускать отдельной последовательной очередью с отключённой сетью; LLM перед ASR выгружать.

## Зафиксированные исходники и модель

Проверено 22.09.2026 по первичным источникам:

- whisper.cpp **v1.9.4**, commit **927cfce34f31707e17f2bff35c349632fb9e2c3a**. [Официальный release API](https://api.github.com/repos/ggml-org/whisper.cpp/releases/latest), [исходники этого commit](https://github.com/ggml-org/whisper.cpp/tree/927cfce34f31707e17f2bff35c349632fb9e2c3a).
- Многоязычный **ggml-small.bin**, около 488 MB. SHA256 **1be3a9b2063867b937e64e2ec7483364a79917e157fa98c5d94b5c1fffea987b** — поле SHA256, не Xet hash. [Официально рекомендованный репозиторий модели](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-small.bin), [список моделей whisper.cpp](https://github.com/ggml-org/whisper.cpp/blob/927cfce34f31707e17f2bff35c349632fb9e2c3a/models/README.md).
- [Скачать модель с фиксированной ревизией](https://huggingface.co/ggerganov/whisper.cpp/resolve/5359861c739e955e79d9a303bcbc70fb988958b1/ggml-small.bin).
- Модель без суффикса .en: английский вариант для русских звонков не подходит. Ориентир памяти для small — около 852 MB; фактический пик всей обработки нужно измерять. [Таблица whisper.cpp](https://github.com/ggml-org/whisper.cpp#memory-usage).

Рекомендация установки: клонировать официальный репозиторий в отдельный каталог, выполнить git checkout --detach 927cfce34f31707e17f2bff35c349632fb9e2c3a и проверить git rev-parse HEAD. Собрать на целевом CPU:

    cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
      -DBUILD_SHARED_LIBS=OFF -DWHISPER_BUILD_TESTS=OFF \
      -DWHISPER_BUILD_SERVER=OFF -DWHISPER_BUILD_IS_DEV=OFF \
      -DWHISPER_CURL=OFF -DGGML_CUDA=OFF -DGGML_RPC=OFF
    cmake --build build --config Release --target whisper-cli -j2

Скачать модель отдельно по указанному URL и сверить sha256sum. Модель и бинарник хранить по неизменяемым путям, доступным процессу только для чтения. Обёртка повторно проверяет модель и включает SHA256 бинарника в ключ кеша; на Linux оба файла закреплены открытыми дескрипторами на всё время обработки.

## Контракт

Переменные окружения:

- CRM_CONTROL_RECORDING_DIR — существующий абсолютный каталог записей.
- CRM_CONTROL_WHISPER_CLI — абсолютный путь к настоящему whisper-cli, без symlink.
- CRM_CONTROL_WHISPER_MODEL_PATH — абсолютный путь к модели, без symlink.
- CRM_CONTROL_WHISPER_MODEL_SHA256 — ожидаемый SHA256 модели.

JSON на stdin: filePath, sha256, mimeType; необязательное channelMetadata.
stdout содержит только статус, путь к закрытому результату и счётчики. Текст, интервалы в миллисекундах и хеши сегментов лежат в JSON с правами 0600 внутри .transcribed/local-asr-v1. Ошибки и предупреждения сторонних процессов не попадают в логи.

channelMetadata допускается только от серверного адаптера телефонии:

    {
      "status": "SERVER_VERIFIED_STEREO",
      "recordingSha256": "<SHA256 этих аудиобайтов>",
      "proofId": "<идентификатор подтверждения телефонии>",
      "channels": [
        {"channel": 0, "role": "manager", "actorId": "<id менеджера>"},
        {"channel": 1, "role": "customer", "actorId": "<id контакта>"}
      ]
    }

Само наличие двух каналов ничего не доказывает: провайдер должен подтверждать принадлежность изолированных каналов участникам. Не принимать этот объект из пользовательского HTTP-запроса. Без него оба канала сохраняются отдельно с ролью unknown; из голоса, порядка реплик и ответа Whisper роли не выводятся.

Каждый результат имеет status: UNVERIFIED и сегменты quality: ASR_UNVERIFIED. processingComplete означает только завершение декодирования и работы модели, не достоверность слов или полноту истории общения. Ошибка второго канала сохраняет первый как неполный результат; такой результат не кешируется.

Лимиты: 100 MiB исходник, 30 минут, 900 секунд на обработку, 2 GiB адресного пространства на Linux, 2 потока Whisper. WAV/MP3/FLAC/OGG/M4A/MP4/AAC/AMR определяются по содержимому; принудительный demuxer исключает плейлисты. Временные файлы удаляются после обработки. Для ограничения всей группы процессов нужны также лимиты отдельного systemd-сервиса.

Ключ кеша включает хеш записи, модели, бинарника, версию обёртки и подтверждение каналов. Обновление FFmpeg или логики нормализации требует новой версии обёртки.

## Проверка

    python3 -B -m unittest discover -s scripts/crm-control-local -p test_transcribe.py -v
    python3 -B -m unittest discover -s scripts/crm-control-local -p test_transcribe_e2e.py -v

Первый набор использует синтетические WAV и подставные ответы движка. Второй требует настроенной модели и настоящих CLI, создаёт временные записи тишины и проверяет выполнение, метаданные и кеш. Это проверка подключения, не оценка точности распознавания речи.
